# Planning Documents

This folder contains planning notes, roadmap drafts and project-direction
documents for the Smart Room Realtime Control Platform.

Planning documents are guidance, not the source of truth for current system
behavior. They describe intent, possible scope, learning goals and staged
delivery ideas. They may be older, broader or more exploratory than the binding
architecture and decisions.

The source of truth for the system is always:

- the current architecture documentation in `docs/architecture`,
- accepted decisions in `docs/decisions`.

Tests and executable scenarios are verification assets. Application behavior is
implementation evidence. When either one disagrees with the documented
architecture or accepted decisions, treat the mismatch as drift to investigate.

Use this folder to understand where the project is heading and why certain
themes matter, such as realtime UX, event modeling, reliability, minimal
hardware and AI-assisted development. When a planning idea becomes a durable
system rule, move it or restate it in the architecture or decision documents.
